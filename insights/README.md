# Insights — personal work folders

One folder per person. This is your scratch space: notes, experiments, things you read, half-ideas, disagreements with the framework. No review needed, no structure required — but if you follow the template it's easier for the rest of us to skim.

```
insights/
  _template/   ← copy this to start yours
  hugo/        Hugo G. Grañena (@Hugongra)
  claudia/     Claudia Agromayor (@ClaudiaAgromayor)
  glenda/      @glendambo25
  daniel/      Daniel Aguilera (@DanielAguileraICAI)
  <your-name>/ ← anyone else (Luis?) — copy _template
```

**Promotion rule:** when something in your folder becomes team knowledge (a decision, a verified fact, a design), move it into [`../knowledge/`](../knowledge/README.md) and add a changelog line there.

**Daily rhythm (suggested):** end of day, add 3 bullets to your `log.md` — what you learned, what you're unsure about, what you need from others. That's the input for the next morning's sync.
