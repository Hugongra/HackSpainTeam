# Synthetic rogue fixtures

Generated by [`../ar_fixtures.py`](../ar_fixtures.py); method and rationale in
[`../knowledge/15-rogue-scenario-design.md`](../knowledge/15-rogue-scenario-design.md).

These are **synthetic payloads at the Custom-LLM boundary** — what HappyRobot would POST to
our inline endpoint (`request`) and what a rogue model would return (`completion`). They exist
because the dangerous behaviour classes (destructive commands, platform sabotage, bulk
exfiltration, goal deviation, covert channels) must never be induced on a live agent: the guard
is a pure function of this JSON, so it can be tested without an agent, a platform, or a side effect.

**Nothing here executes.** Every host is `*.invalid`, every token is `sk_live_FAKE_…`, every
destructive payload is elided (`<ELIDED>`) — recognisable to a detector, useless as a command.
They are inputs to a guard in the same sense that EICAR is an input to an antivirus.

| File | What |
|---|---|
| `F*-*.inline.json` | one fixture each: `request` (messages + tools), `completion` (the rogue response), `expected` (labelled verdicts) |
| `corpus.jsonl` | the same set flattened to the shape `ar_guard` scores |

14 fixtures: 8 dangerous (F1 plotting against the principal · F2 dangerous code · F3 platform
sabotage · F4 bulk exfiltration · F5 goal deviation · F6 covert channel) and **6 benign twins**
that share each dangerous case's surface features. The twins are the important half — they are
what keeps precision honest, and they caught two false positives in the guard.

```bash
/usr/bin/python3 ar_fixtures.py --list        # families and fixtures
/usr/bin/python3 ar_fixtures.py               # regenerate (deterministic)
/usr/bin/python3 ar_score.py fixtures/corpus.jsonl
/usr/bin/python3 ar_dashboard.py --verdicts fixtures/verdicts.json
/usr/bin/python3 ar_cluster.py                # unsupervised view of the same set
```

The twins are also what makes this corpus **adversarial to unsupervised clustering**: shared
surface features are exactly what a distance metric sees, so each dangerous case's nearest
neighbour is usually its own benign twin. [`ar_cluster.py`](../ar_cluster.py) measures that —
malignancy ARI +0.012 (p=0.58) while tool modality comes out at +0.28 — and
[`knowledge/16`](../knowledge/16-unsupervised-clustering.md) writes up why.
